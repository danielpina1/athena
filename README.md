# Athena

Athena is a single Go binary (`athena`) that drives Claude Code and Codex sessions as workers: it tracks tickets, assignments and reports, gates tool use through hooks, and surfaces what needs a person's attention. See the [design spec](docs/superpowers/specs/2026-11-03-athena-design.md) for the full picture; behavioral reference docs live in [docs/reference](docs/reference).
